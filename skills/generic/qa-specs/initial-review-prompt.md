# Initial Review Prompt (QA)

## Purpose

Audit spec for completeness before implementation.

## Contract

- Check for: acceptance criteria, edge cases, error handling, ownership
- List gaps as `NEEDS FURTHER REFINEMENT`
- If complete → `APPROVED`

## Format

```
## Findings
- [Gap 1]
- [Gap 2]

## Status
NEEDS FURTHER REFINEMENT / APPROVED
```
