# Initial Review Prompt (Dev)

## Purpose

Align with spec before implementation.

## Contract

- Confirm understanding of intent
- List any ASSUMPTIONs needed
- Find issues (solutions-first)

## Format

```
## Understanding
- [Intent summary]

## Assumptions
- [ASSUMPTION 1]
- [ASSUMPTION 2]

## Issues Found
- [Issue 1]
- [Issue 2]

## Status
APPROVED / NEEDS FURTHER REFINEMENT
```
